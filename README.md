# 🏋️ Gym Website

A responsive and performance-optimized gym website built using **HTML, CSS, and JavaScript**.  
The project focuses on clean UI, smooth navigation, and fast load times across devices.

---

## 🚀 Live Demo
🔗 **Live Link:** https://rishabh1824.github.io/Gym/

## 💻 GitHub Repository
🔗 https://github.com/rishabh1824/Gym

---

## 📌 Features

- 📄 **Multi-page layout** including:
  - Home
  - About
  - Contact
  - Fitness Plans
- 📱 **Fully responsive design** for mobile, tablet, and desktop
- ⚡ **Performance optimized** using asset minimization and caching techniques
- 🎯 **Clean UI/UX** with intuitive navigation
- 🌐 **Cross-browser compatible**

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Styling:** CSS Flexbox, Media Queries  
- **Optimization:** Asset compression, browser caching
